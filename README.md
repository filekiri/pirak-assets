# pirak-assets

Static images for the Pirak Condo project (Choeng Thale, Phuket): unit layouts and building floor plans. Public storage for use on the website, in catalogues and in presentations.

## Structure

`plans/` all images. JPEG, max width 2000 px, quality 85.

Unit layouts, 3 variants per type:

`plan_<type>.jpg` base plan
`plan_<type>_color.jpg` color plan
`plan_<type>_marketing.jpg` marketing sheet

Types: `1b_a`, `1b_b`, `1b_c`, `2b`, `3b`.

Floor plans:

`floor_a_02.jpg` ... `floor_a_07.jpg` Building 1
`floor_b_02.jpg` ... `floor_b_07.jpg` Building 2
